# Romeu SQL 0.1.0-alpha.18

## Destaques

- Navegue de uma chave estrangeira para o registro relacionado em uma nova aba, já filtrada pelo valor da relação.
- Visualize valores completos de todos os campos do banco, incluindo chaves de API, no preview, JSON e exportações.

## Correções

- As relações de chave estrangeira são detectadas diretamente no schema para PostgreSQL, MySQL e SQLite.

## Aviso de alpha

Romeu SQL ainda está em desenvolvimento. Enquanto estiver em alpha, priorize validar fluxos críticos antes de usar em dados sensíveis.
